# Alley Jam — 2v2 arcade hoops

Play in your browser: https://liloopy-jpe.github.io/alley-jam-play/

Four 2:00 quarters, you (Rex) + Mira vs the Harbor Wolves. Sound starts after your first click or key press.

**Modes** (title screen → MODE, or A/D when MODE is selected):
- **Level Up** (default): everyone starts at SPD/PWR/DXT 5 and earns levels during the match — shots and jukes raise DXT, dunks and blocks raise PWR, fast breaks and turbo raise SPD. Catch-up XP and per-quarter caps keep it fair.
- **Classic**: fixed maxed ratings (all 10). Same game feel as earlier builds.

## Controls
| Key | Action |
|---|---|
| WASD | Move |
| Shift (hold) | Turbo: run faster, jump higher, dunk from farther. Drains the turbo bar. |
| Space (hold) | Shoot: release in the green band of the meter above Rex for PERFECT. Near the rim = dunk. |
| Space on defense | Jump to block a shot |
| E | Pass on offense · call for the ball when Mira has it · steal on defense |
| E while ON FIRE | Pass to a teammate near the rim for an alley-oop |
| Q | Crossover / spin: costs turbo, can shake a close defender off their feet |
| R | Shove (off-ball or on defense): can knock the ball loose or throw off a shot |
| Esc / P | Pause / resume |
| M | Sound on/off |
| − / + | Volume down / up (10 steps) |
| Space at FINAL | Rematch (Esc: back to title) |
